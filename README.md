# federalist-calibration-audit

Code and data for **"Blind SVD and the Illusion of Invariance: A Calibration Audit of Stylometric Pipelines on the Federalist Papers"**.
[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.24102096.svg)](https://doi.org/10.5281/zenodo.24102096)

The repository reproduces every number and figure in the article: the three SVD pipelines (blind centred, blind standardised, calibrated), Cohen's *d* and Mann–Whitney comparisons, Hotelling's T² classifications of the twelve disputed papers, the 500-specification curve, and Figures 1–4.
